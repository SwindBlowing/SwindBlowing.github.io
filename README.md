# swindblowing.github.io

Lang Lin's homepage: <https://swindblowing.github.io/>

A single static page (`index.html` + `stylesheet.css`, images in `images/`), served by GitHub Pages from the `main` branch. `.nojekyll` turns off Jekyll, so there is no build step: edit `index.html` and push.

Design adapted from [Chengzhong Wang's homepage](https://aronwang02.github.io/).
